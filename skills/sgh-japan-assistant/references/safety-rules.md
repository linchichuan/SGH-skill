# Safety Rules

1. Public service discovery, brief creation, readiness checks, and inquiry drafting cannot create any external action.
2. Draft creation cannot place a call.
3. This public repository and local Skill include zero SGH call credits, external AI/API credits, implementation credits, and free human-service credits.
4. Only `confirm_assistance_request` may queue supported Phase 1 execution, and only after the server atomically verifies and reserves a request-bound paid contract, prepaid credit, or issuer-funded service-scoped SGH Pass.
5. Never describe queued, calling, or waiting work as confirmed.
6. A confirmed reservation requires evidence supplied by the contacted business.
7. Unknown provider states fail into human review.
8. Do not accept emergency requests, impersonation, harassment, fraud, or bypassing business rules.
9. The public Skill must not collect diagnosis, detailed symptoms, medical records, passport data, payment-card data, passwords, authentication codes, access tokens, or secrets.
10. Share only fields included in the user's explicit consent snapshot.
11. A cancellation tool cancels the SGH task only; it does not imply a third-party reservation has been cancelled.
12. A discovery-only or Menu Bridge entitlement cannot authorize phone, reservation, cancellation, rescheduling, external AI processing, implementation, or human-service execution.
13. Direct human handoff stays disabled until a service-scoped human entitlement is verified and its credit is atomically reserved.
14. Keep medical coordination, regulated import consultation, commerce, phone execution, and system implementation in separate responsibility and contract lanes.
15. Label Demo, MVP, private beta, consultation-only, and unverified production capabilities accurately.
16. Do not put sensitive information in MCP `_meta`, logs, n8n execution data, analytics, or public GitHub issues.
17. Explicit no-action language overrides execution intent; do not create a server-side draft when the user asks for local preparation only.
18. Resolve relative dates and timezone before creating or confirming a request.
19. Installing or authenticating any repository, Skill, connector, plugin, or client does not grant SGH entitlement or consent.
20. If Remote MCP is unavailable or not verified live, do not simulate execution.
21. Public LINE guidance must not send or push a message, initialize LIFF, link an account, publish a Rich Menu, call an external AI model, create a patient, submit a booking, or consume an SGH-owned provider allowance.
22. Adding a LINE Official Account or viewing a public Rich Menu does not grant API scope, external-AI credit, patient-service entitlement, phone credit, or human-work credit.
