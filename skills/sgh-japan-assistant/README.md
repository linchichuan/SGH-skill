# SGH Japan Assistant Skill Package

This folder contains the installable Agent Skill instructions. The executable Remote MCP gateway lives at repository root under `src/`.

- `SKILL.md`: agent workflow and state-safety rules
- `skill.json`: package metadata and remote MCP declaration
- `references/tool-contracts.md`: tool inputs and output contract
- `references/safety-rules.md`: consent、data and status safeguards
- `references/authentication.md`: OAuth scopes and client setup
