# SGH Assistant 料金及び見積方針

> [!WARNING]
> **公開前レビュー用ドラフト（v0.1）／未施行**
> 正式な金額及び課金条件は、公開URLで掲示する施行中の文書と、各requestの確認画面に表示する見積によります。

最終更新日：2026年7月20日

## 1. 対象

本方針は、新義豊株式会社（以下「当社」といいます）が提供するSGH Japan Assistant / SGH Service Skill（以下「本サービス」といいます）を通じた、日本国内の事業者等への電話、予約、変更、取消、確認及び人的対応に適用します。

## 2. 無料部分と有料部分

| 無料 | 有料 |
|---|---|
| GitHubリポジトリの閲覧・clone | SGHによる対外電話 |
| ローカルSkillのインストール | 実際の予約、変更又は取消 |
| 相談内容・必要情報の整理 | 人による確認、例外対応又は継続フォロー |
| 外部実行を伴わない対応可否チェック | 通信、音声AI、通知その他原価を伴う処理 |
| 電話を開始しないdraft作成 | 検証済みの実行結果の作成・提供 |

公開コードのMIT Licenseは、有料サービスの利用権、通話クレジット、人的対応枠又はSGH Passを付与しません。

## 3. request単位の見積

有料実行は、一つの`request_id`に一つの有効な見積を関連付けて管理します。見積には、少なくとも次の内容を表示します。

- `request_id`、`quote_id`及び見積バージョン
- 対象事業者、電話番号、依頼目的及び希望期限
- サービス区分、含まれる電話試行回数及び人的作業の範囲
- 税込金額、通貨、支払方法及び決済の時点
- 未接続、話中、留守番電話、再試行、折返し及び人的対応の料金条件
- キャンセル、決済承認の解除及び返金条件
- 利用者が相手先へ共有することを承認する情報
- 見積の有効期限

見積は当該requestにのみ有効であり、別のrequestへ転用できません。対象、目的、共有情報、回数、人的作業又は料金条件が変わる場合は、新しい見積又は新しいバージョンを提示し、改めて明確な確認を受けます。

## 4. 固定料金について

標準料金、未接続時の料金、再試行料金及び人的対応料金の固定額は、正式公開前に確定する運用設定項目です。本ドラフトでは、未確定の金額を推測して掲載しません。

正式提供時には、次のいずれかにより、申込みの最終確認前に具体的な税込金額又は算定方法を表示します。

1. 公開料金表に掲載する標準料金
2. requestごとの個別見積
3. 法人契約又は提携契約で合意した料金
4. 購入済み又は発行元負担のSGH Passに定める利用枠

確認画面又は見積に記載のない追加料金を、利用者の新たな明示確認なく請求しません。

## 5. 決済承認と売上確定

1. draft作成、必要情報の確認及び見積の表示だけでは、電話又は人的作業を開始しません。
2. 利用者が対象、共有情報、料金及び取消条件を明確に確認した後に限り、決済承認又は利用枠の確保を行います。
3. 決済承認は、支払手段の利用可能額を一時的に確保する手続であり、売上確定と異なる場合があります。
4. 売上確定は、実際の実行結果及び利用者が確認した見積の課金条件に従います。
5. 同じ確認操作が再送されても、同じidempotency keyについて重複請求、重複利用枠控除又は重複発信を行いません。
6. 決済承認又は利用資格をrequestへ関連付けられない場合、そのrequestを実行キューへ送りません。

## 6. SGH Pass

SGH Passは、無制限の無料電話Tokenではなく、費用負担者、利用対象及び上限を示す利用資格です。次の条件を一つの確認処理で満たす場合に限り利用できます。

- Passが当該利用者又は許可された利用者に有効であること
- tenant及び発行元（issuer）がrequestと一致すること
- 電話、予約、人的対応等のservice scopeが依頼内容を含むこと
- 有効期間内であること
- 必要な電話・task・人的対応の利用枠が残っていること
- 失効、取消、既使用又は不正利用の状態でないこと

利用者負担が0円のsponsored Passであっても、提携事業者その他の発行元が費用を負担します。Menu Bridge等の情報閲覧・宣伝用Passを、電話、予約又は人的対応に転用することはできません。

## 7. 実行結果別の料金

- **実行開始前の取消**：実行料金は発生せず、決済承認を解除し、確保済みの未使用枠を戻します。
- **未接続、話中又は留守番電話**：見積で具体的な試行料金又は算定方法を表示し、利用者が確認した場合に限り、その条件を適用します。
- **再試行又は折返し対応**：見積の範囲外となる場合は、新たな料金及び条件を提示し、確認前に追加実行しません。
- **人的対応**：対象作業、時間又は単位、税込金額若しくは算定方法を見積に表示し、必要な人的作業枠を確保してから開始します。
- **相手先による拒否**：予約等の成立を保証するものではありません。実際に行った電話試行又は人的作業への料金は、事前に確認された見積条件によります。
- **当社都合で実行しなかった場合**：未実行部分を請求せず、該当する決済承認又は未使用枠を解除します。

詳しくは[キャンセル・返金方針](cancellation-refund.md)をご確認ください。

## 8. 税金及び通信費等

利用者向けに表示する金額は、別途明示する場合を除き、日本の消費税を含む税込金額とします。本サービスへアクセスするための通信料、端末費用その他利用者側で生じる費用は、利用者の負担です。
