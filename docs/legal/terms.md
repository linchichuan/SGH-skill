# SGH Assistant 利用規約

> **公開前レビュー用ドラフト（v0.1）／未施行**
> 本ドラフトは正式な契約条件ではありません。正式な公開URLで施行日及びバージョンを掲示し、申込み時に同意を取得した文書が適用されます。

最終更新日：2026年7月20日

新義豊株式会社（以下「当社」といいます）が提供するSGH Japan Assistant / SGH Service Skillに関する利用条件を、以下のとおり定めます。

## 第1条（適用）

1. 本規約は、Agent Skill、Remote MCP、Webその他当社が指定する入口を通じて提供する電話、予約、変更、取消、確認、結果通知及び人的対応（以下「本サービス」といいます）に適用されます。
2. 利用者は、本規約、[料金及び見積方針](pricing.md)、[キャンセル・返金方針](cancellation-refund.md)、[プライバシーポリシー](privacy.md)、[適正利用ガイドライン](aup.md)及びrequestごとの確認画面に同意して本サービスを利用します。
3. 個別契約、申込書、見積又は提携契約に本規約と異なる条件がある場合、当該個別条件が優先します。
4. GitHub上のREADME、サンプル、デモ及びマーケティング資料は、明示されない限りサービスの品質、成果又は無償提供を保証する契約条件ではありません。

## 第2条（定義）

1. 「request」とは、一つの対象、目的、共有情報、期限及び料金条件により識別される個別依頼をいいます。
2. 「draft」とは、依頼内容を整理した未実行の下書きをいいます。
3. 「見積」とは、request ID、金額、範囲、試行回数、人的作業、取消条件、有効期限等を固定した提示をいいます。
4. 「SGH Pass」とは、購入者、契約企業又は提携先等の費用負担に基づき、tenant、issuer、service scope、利用回数、有効期限及び利用枠を限定した利用資格をいいます。
5. 「対応Agent」とは、利用者の指示を受けて本サービスへ接続するChatGPT、Codex、Claudeその他のAI又はソフトウェアをいいます。

## 第3条（利用資格及び本人確認）

1. 利用者は、契約を締結する法的能力を有する者とします。未成年者その他法定代理人の同意が必要な者は、必要な同意を得なければなりません。
2. 当社は、OAuthその他の方法により本人確認、権限確認、tenant確認又は不正利用審査を行うことができます。
3. 利用者は、認証情報、Pass Token、request ID及び接続済みAgentを適切に管理し、不正利用のおそれがある場合は速やかに当社へ連絡するものとします。
4. 当社は、本人又は権限を確認できない依頼、費用負担を確認できない依頼その他安全な実行が困難な依頼を拒否又は保留できます。

## 第4条（申込み及び明示確認）

1. draftの作成は、有料サービスの申込み、電話の開始又は予約の成立を意味しません。
2. 当社は、実行前に、対象、目的、電話番号、共有情報、希望日時、料金、取消条件及び不足情報を提示します。
3. 利用者が、同一request及び同一見積バージョンについて明確に確認し、有効な決済承認、契約枠又はSGH Passが確保された時点で、有料実行の申込みが成立します。
4. 内容又は料金条件が変更された場合、当社は新しい見積を提示し、改めて確認を求めます。
5. 対応Agentが利用者の明確な指示なく確認操作を行った場合、当社は実行を停止し、本人への再確認を求めることができます。

## 第5条（サービスの実行と状態表示）

1. 当社は、申込み成立後、相手先の営業時間、希望期限、通信状況、担当者の稼働その他の条件を考慮して実行します。
2. `QUEUED`、`CALLING`、`WAITING_FOR_BUSINESS`又は`CALLBACK_REQUIRED`は、予約、変更、取消その他の結果が成立したことを意味しません。
3. `CONFIRMED`又は`COMPLETED`であっても、当社が記録した確認内容の範囲を超える成果を保証するものではありません。
4. 当社は、相手先の回答、受入れ、空席、診療可否、価格、営業時間又は将来の行為を保証しません。
5. 緊急性、安全性、法令、相手先の意思、技術上の制約又は当社の運用基準により、requestの全部又は一部を実行できない場合があります。

## 第6条（料金、決済及びSGH Pass）

1. GitHubリポジトリの閲覧、clone及びローカルSkillのインストールは無料ですが、電話、予約実行、変更、取消及び人的対応は有料です。
2. 料金は、申込み前にrequestごとの確認画面、公開料金表、個別見積又は個別契約で税込表示します。
3. 未接続、話中、留守番電話、再試行、折返し又は人的対応に料金が生じる場合は、その具体的な金額又は算定方法を確認画面に表示します。
4. SGH Passは、tenant、issuer、service scope、有効期限及び必要な残高が当該requestと一致する場合に限り使用できます。
5. 当社は、同じidempotency keyの再送による重複発信、重複請求又は重複利用枠控除を防止する措置を講じます。
6. 料金及び決済の詳細は[料金及び見積方針](pricing.md)によります。

## 第7条（キャンセル及び返金）

1. 利用者は、実行開始前であれば、当社所定の方法でrequestを取り消すことができます。この場合、実行料金は発生せず、決済承認を解除し、未使用の確保枠を戻します。
2. 電話試行又は人的作業の開始後は、開始済み部分について、利用者が確認した見積の料金条件を適用します。
3. 相手先が応答しないこと又は依頼を受け入れないことだけを理由として、予約等の成立を保証し又は開始済み作業を当然に無料とするものではありません。ただし、料金は事前に明示された条件に限ります。
4. 詳細は[キャンセル・返金方針](cancellation-refund.md)によります。

## 第8条（利用者の責任）

1. 利用者は、正確かつ最新の対象、電話番号、目的、希望日時及び連絡条件を提供します。
2. 利用者は、当社が相手先へ伝える氏名、連絡先、予約情報その他の情報について、提供及び第三者への伝達に必要な権限、同意又は適法な根拠を有することを確認します。
3. 利用者は、相手先の規約、取消料、診療費、商品代金その他相手先との取引条件を自ら確認し、当社の確認結果だけに依存して重要な判断を行わないものとします。
4. 利用者が誤った情報又は不足情報を提供したことによる再実行、取消料その他の費用は、事前に提示される条件に従い利用者が負担します。

## 第9条（医療その他慎重な取扱いを要する依頼）

1. 本サービスは、医療機関の受入条件、予約方法、営業時間その他事務的事項の確認を支援するものであり、診断、治療、処方、服薬指示又は医療判断を行いません。
2. 緊急通報、生命・身体に差し迫った危険への対応には利用できません。緊急時は、日本国内では119その他適切な緊急窓口へ直接連絡してください。
3. 診療歴、症状、服薬、障害その他の要配慮個人情報は、依頼に必要な最小限とし、共有対象及び目的を明示して確認を受けます。
4. 当社は、専門資格又は法的権限を要する依頼、成果の保証を求める依頼その他適切に対応できない依頼を拒否できます。

## 第10条（録音、文字起こし及びAI処理）

1. 本サービスは、品質管理、結果確認、安全確保及び紛争対応のため、必要に応じて通話の録音、文字起こし、要約又はAI処理を行う場合があります。
2. 当社は、適用される法令、相手先の意思及び業務上の必要性を踏まえ、必要な告知又は同意取得の方法を定めます。
3. AIの文字起こし、翻訳又は要約には誤りが含まれることがあります。重要な日時、金額、氏名、条件及び医療関連情報は、検証済み記録又は相手先の正式文書で確認してください。

利用者は、法令違反、詐欺、なりすまし、嫌がらせ、相手先が拒否した後の反復発信、決済又はPassの回避、認証情報の不正利用、秘密情報の不正取得その他[適正利用ガイドライン](aup.md)に定める行為を行ってはなりません。
