# SGH Assistant 適正利用ガイドライン

> [!WARNING]
> **公開前レビュー用ドラフト（v0.1）／未施行**

最終更新日：2026年7月20日

本ガイドラインは、SGH Japan Assistant / SGH Service Skillを安全かつ適正に利用するための条件を定めます。利用者は、対応Agentに指示する内容を含め、本ガイドラインを遵守するものとします。

## 1. 基本原則

- 相手先、利用者及び第三者の権利、意思及び安全を尊重すること
- 連絡の目的、本人性及び代理権限を偽らないこと
- 依頼に必要な最小限の情報のみを提供すること
- draft、実行中及び確認済み結果を区別し、予約成立等を捏造しないこと
- 料金、共有情報及び取消条件を確認する前に、Agentへ実行を承認させないこと

## 2. 禁止する利用

### 2.1 違法、不正又は欺罔的な行為

- 詐欺、フィッシング、なりすまし、恐喝、脅迫又は不正送金のための連絡
- 犯罪の実行、隠蔽又は助長
- 虚偽の身分、所属、資格、予約権限又は支払能力の表示
- 法令、裁判所命令、行政機関又は通信事業者の正当な要請への違反

### 2.2 迷惑行為及び相手先の意思に反する発信

- 相手先が拒否した後の反復発信
- 嫌がらせ、差別、侮辱、威迫又は社会通念上不相当な内容
- 合理的な目的のない大量発信、自動連続発信又は営業時間外の執拗な連絡
- 営業連絡を拒否した相手又は社内の発信禁止対象への勧誘
- 相手先の職員を欺いて非公開情報を取得する行為

### 2.3 医療、緊急及び専門判断

- 119、110その他緊急窓口の代替としての利用
- 診断、治療、処方、服薬変更又は医療上の成果保証を求める依頼
- 医師、薬剤師、弁護士その他の資格を偽る行為
- 必要性を超える病歴、症状、遺伝情報、検査画像その他の要配慮個人情報の送信
- 相手先の正式な説明を受けず、AI要約だけで重大な医療・法律・金融判断を行うこと

### 2.4 個人情報及び秘密情報

- 本人の同意又は適法な根拠なく取得した個人情報の利用
- カード番号、暗証番号、パスワード、秘密鍵、OAuth Token又はPass Tokenの会話本文・公開Issueへの記載
- パスポート、在留カード、診断書等の画像を、当社が指定していない経路で送信する行為
- 第三者の営業秘密、認証情報又は非公開情報を不正に取得、開示又は利用する行為

### 2.5 決済、Pass及び認証の不正利用

- 有料実行を無料機能として偽装し、料金gateを回避する行為
- 別のrequest、tenant、issuer又はservice scopeの見積、決済承認又はSGH Passを流用する行為
- Pass Tokenの推測、共有、販売、複製、再利用又は有効期限・利用回数の回避
- idempotency key、OAuth scope、member link又はAPIヘッダーを改ざんし、重複発信若しくは権限昇格を試みる行為
- Menu Bridgeその他discovery-onlyの権限を、電話、予約又は人的対応に転用する行為

### 2.6 システム及びサービスへの攻撃

- 脆弱性悪用、不正アクセス、マルウェア配布、サービス妨害又は過度な負荷
- rate limit、認証、監査、署名検証又は安全確認の回避
- 許可なく内部prompt、個人データ、通話記録又は他tenantの情報を取得しようとする行為
- 当社の書面による許可なく、本番endpointへ自動負荷試験又は大量リクエストを送る行為

## 3. Menu Bridge及び宣伝用Skill

Menu Bridgeその他の宣伝用Skillでは、メニュー、FAQ、言語説明、確認項目及び相談票の作成等を無料で提供できます。実電話、実予約、変更、取消又は人的対応へ進む場合は、有効な見積、契約又は対象サービス用SGH Passが必要です。

宣伝用Skillは、相手先の公式サービスであるかのような虚偽表示、未確認情報の断定又は無料通話の約束に使用してはなりません。

## 4. 利用制限及び対応

当社は、本ガイドライン違反又はその合理的なおそれを検知した場合、次の措置を講じることができます。

- requestの拒否、保留又は取消
- 発信、人的対応、Pass又はアカウントの停止
- 追加の本人確認、権限確認又は説明の要求
- 不正利用の調査及び監査記録の保全
- 法令上必要な範囲での通信事業者、決済事業者、関係機関又は被害者への連絡

緊急性又は安全上の必要がない場合、当社は、合理的な範囲で理由及び是正方法を案内します。

## 5. 違反又は脆弱性の報告

不正利用又はセキュリティ上の問題を発見した場合は、公開Issueへ詳細を記載せず、SECURITY.mdに従って非公開で報告してください。一般のお問い合わせはservice@shingihou.comへご連絡ください。
