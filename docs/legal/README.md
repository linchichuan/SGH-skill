## 適用対象

これらの文書は、Agent Skill、Remote MCP、Web、ChatGPT、Codex、Claudeその他対応Agentを入口として利用する「SGH Japan Assistant / SGH Service Skill」の電話・予約・確認・人的対応サービスを対象とするドラフトです。

SGH Phoneの法人向けSaaS契約、個別の業務委託契約又は提携先固有のサービスについて別の条件が提示された場合は、その個別条件が優先します。

## コード公開とサービス提供の区別

- GitHubリポジトリの閲覧、clone及びローカルSkillのインストールは無料です。
- MIT Licenseはこのリポジトリのソースコードにのみ適用されます。
- SGHによる電話、実予約、変更、取消、結果確認及び人的対応は無料ではありません。
- リポジトリの公開又はSkillのインストールによって、通話枠、人的対応枠、決済済みクレジット又はSGH Passは付与されません。
- `DRAFT`、`AWAITING_CONFIRMATION`又は`QUEUED`は、相手先による予約・申込みの成立を意味しません。

## 正式公開前に確定する運用設定

次の事項は、曖昧なまま利用者へ適用せず、正式提供を開始する前に管理画面、見積契約及び正式文書へ具体的に設定します。

1. 標準料金又は料金算定方法（税込）
2. 未接続、話中、留守番電話、再試行及び人的対応の具体的な料金
3. 決済手段、決済承認・売上確定の時点及び返金処理期間
4. 電話受付時間、サポート対応時間及びサービス提供時間
5. 通話録音、文字起こし、監査ログその他データ区分ごとの保存期間
6. 利用する外部委託先、処理するデータ、所在国及び外国移転に必要な説明
7. 本文書の施行日、正式バージョン及び公開URL

上記が確定していない段階では、有料実行を本番提供として開始しません。各requestでは、税込金額、課金条件、取消条件及び共有データを確認画面に明示し、利用者の明確な確認前に電話又は人的作業を開始しません。

## 条件の優先順位

矛盾がある場合は、強行法規を前提として、原則として次の順序で適用します。

1. 個別契約、申込書又は提携契約
2. 利用者が確認したrequest固有の見積及び確認画面
3. 正式な公開URLで掲示された施行中の利用規約・料金・取消方針
4. 本リポジトリの説明資料
